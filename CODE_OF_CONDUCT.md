# Code of conduct

Treat participants with respect. Welcome questions and different backgrounds,
give constructive feedback about the work, and respect other people's time,
privacy, and boundaries. Disagreement about technical decisions is welcome;
personal attacks are not.

Harassment, discrimination, threats, sexual harassment, sustained disruption,
and publishing another person's private information are unacceptable. These
standards apply in repository discussions, issues, pull requests, and other
spaces where participants represent this project.

## Raise a concern

Ask @pmcorcoran for a private contact method. If a public issue or comment is the
only available route, write only that you would like private contact about a
conduct concern. Do not post the incident details, names, screenshots, or other
personal information there. No conduct email has been selected. Share details
only after a private channel is established; request an alternative reviewer
if the concern involves the person receiving it.

The maintainer will consider context, hear relevant perspectives, and limit
sharing of sensitive details to what is needed to address the concern. Responses
may include a request to change behavior, removal of content, or temporary or
permanent restrictions on participation. Serious or repeated misconduct can
result in immediate restrictions. Anyone involved should avoid retaliation.

Security vulnerabilities follow the separate [security policy](SECURITY.md).
